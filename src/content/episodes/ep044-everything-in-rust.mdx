## Summary

Mike and Mathias start from the OpenAI Dev Day reaction show, then spend the episode on Rust. Mathias explains why a 2015 Mozilla language, native binaries and strict types, suddenly fits a world where agents write the code humans used to avoid. They go through GitHub's Copilot runtime port from TypeScript, the token bill, Bun's rewrite from Zig after Anthropic's acquisition, and why TypeScript 7 went to Go instead. Mike ties the speedups back to GitHub Actions minutes, and Mathias closes on language servers as semantic feedback the model does not have on its own.

## Key Takeaways

- ▸ Rust compiles to a native binary with no runtime and strict static types. Mathias's point is that agents remove the old reason to avoid it: humans no longer have to write the hard code.
- ▸ GitHub's Copilot runtime port is not open source. The article credits one author, Stephen, plus a handful of people, with agents doing the rest: about 830,000 lines of Rust and almost half a million lines of unit tests, underway since May.
- ▸ They left TypeScript so the engine can embed in products like Excel without shipping a Node runtime. One cited turn went from 5.25 seconds to 290 milliseconds. Resuming a 32-turn session went from 5.6 seconds to about 260 milliseconds.
- ▸ The port spent about 136 billion tokens, roughly 130 billion of them cached, for a bill around $120,000 over three months. Mike's read is that a human team would have taken longer and cost far more, because agents compress the same work into less calendar time.
- ▸ Bun, the JavaScript runtime, package manager, and test runner Claude Code was built on, was acquired by Anthropic and rewritten from Zig. As of v1.4 it is Rust.
- ▸ TypeScript 7 stopped compiling itself in TypeScript and went to Go, not Rust. Anders Hejlsberg's reason, as Mathias relays it, is that Go was close enough to port rather than semantically rewrite. VS Code's roughly 2.3 million lines dropped from about 125 seconds to 10.6 seconds, and that compile time is GitHub Actions money once agents multiply commits.
