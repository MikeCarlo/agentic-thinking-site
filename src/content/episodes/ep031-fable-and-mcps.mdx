## Summary

Mike opens with the realization that the Power BI modeling MCP server supports service principal authentication, not just interactive sign-in, which means a Claude Code desktop session can talk to a model in Fabric with no personal identity and no Pro licence attached. Both hosts note this is aimed at headless and CI/CD scenarios and that passing credentials through environment variables deserves real care. From there: the Power BI MCP server does not appear in the VS Code marketplace as a registered MCP server because it shipped as an extension, so it has to be registered by hand via mcp.json. Matthias walks through the agent host protocol in the July VS Code release, an open-sourced spec that abstracts how VS Code hosts Claude Code, Codex, and Copilot CLI sessions so multiple clients can consume the same running session. The back half turns to economics -- Fable staying available on Max subscriptions at 50% of weekly quota, Anthropic's 50% credit promotion, Kimi 2.7 and the new K3, and the reminder that the provider, not the gateway, sets the data retention policy.

## Key Takeaways

- ▸ The Power BI modeling MCP server supports service principal auth, enabling headless model access without a user identity or a Pro licence, though the model must live in Fabric for the XMLA endpoint.
- ▸ Passing those credentials into a hosted agent means a dedicated secrets environment and an awkward environment-variable prefix -- easy to get wrong and frustrating to debug.
- ▸ The Power BI MCP server ships as a VS Code extension rather than a registered MCP server, so it is filtered out of the marketplace search and must be wired up manually through mcp.json.
- ▸ The agent host protocol, open-sourced in the July VS Code release, abstracts agent hosting into a spec so multiple clients can attach to one running session; it is opt-in via a setting.
- ▸ Fable stays available to Max and enterprise subscribers at 50% of weekly quota, but Pro subscribers need extra credits once the promotional period ends -- and it burns quota fast if left on by accident.
- ▸ Kimi 2.7 costs roughly half Sonnet 5 on input and a fraction of Opus, and the new K3 lands near frontier capability at a far lower price point, with open weights due within a week.
- ▸ Zero data retention is a property of the provider behind a gateway, not the gateway itself, so routing through Vercel AI Gateway or OpenRouter still requires checking each provider's policy.
