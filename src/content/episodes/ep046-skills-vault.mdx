## Summary

Tommy Puglia joins Mike to demo Skill Vault, a free open source project on Tommy's GitHub that keeps agent skills in one place and links them out to every harness that uses them. The problem is drift: Claude Code, Claude Desktop, Cursor, Copilot, project folders, and Notion each want their own copy, and nobody knows which one is current. Skill Vault stores the skills in a single folder or Git repo, pushes them to each target with symbolic links or Windows junctions, keeps version history, and tracks the source repo of any skill you adopt so upstream updates show up later. Tommy walks through settings, auto tagging, adopting a logo design skill from GitHub, pushing skills to the Notion Skills library, and asking the built-in assistant to find Hyperframes skills. Along the way Mike makes the case for building agent tools data first, CLI second, and UI last.

## Key Takeaways

- ▸ Skill drift is the real problem. When you switch from Claude to Copilot because you ran out of tokens, or move between machines and repos, the business logic in your skills has to come with you, and copies fall out of sync fast.
- ▸ Skill Vault pushes links, not copies. Edit a skill once in the vault and every target sees the change. It is Windows only for now, with both a visual app and a CLI, and every action in the app maps to a CLI command so agents can drive it too.
- ▸ Mike's build order for agentic tools: start with the data you care about, wrap it in a CLI that covers the workflows, then build the UI. Tommy built Skill Vault the same way, all CLI at the start.
- ▸ Adopting a skill from a Git repo remembers where it came from. When Microsoft updates the Skills for Fabric repo or Kurt updates his PBIR skill, Skill Vault flags the update, and the assistant can apply it or help resolve a conflict with your own edits.
- ▸ Claude Desktop no longer shares a skills library with Claude Code, so Tommy syncs skills through the Notion Skills API and the Notion MCP instead of repackaging them by hand.
- ▸ The assistant is a custom harness built on Claude, with five sub agents and ten skills, loosely based on the architecture Alex Powers built for Fabric task flows. It auto tags Tommy's 257 skills and can search GitHub for new skill repos sorted by stars.
- ▸ Mike's soapbox: many Microsoft skills are long and reference heavy. They still add value, but the guidance he has heard from Anthropic is to keep a SKILL.md file under 300 lines, so these cost more tokens.
