## Summary

Mike, Mathias, Ryan, and Tommy from Explicit Measures watch the OpenAI Dev Day 2026 keynote together and react as the announcements land. The centerpiece is Dots, always-on agents that keep context, hand off work, and plug into apps already connected to ChatGPT. The keynote then covers a cheaper daily model, GPT 6.1 Soul, an ultra-fast tier, a Decisions API for near-instant routing, Codex security tooling, and a private-intelligence preview that promises frontier safety without storing customer content. They close on a GPT Live demo where a model plays a generated game in the browser while the panel talks through what is actually new versus a reskin of agents they already use.

## Key Takeaways

- ▸ Dots are pitched as always-on agents that learn how you work, take responsibilities such as bug triage or budget planning, and check in only when a decision needs a human.
- ▸ Onboarding a Dot reuses plugins already connected to ChatGPT, so the agent can act across thousands of apps without a separate integration project.
- ▸ GPT 6.1 Soul is framed as near-Astra intelligence at a fraction of the price, aimed at long agent tasks that reuse context, with an ultra-fast tier around 300 tokens per second for when speed matters more.
- ▸ The Decisions API constrains a model to a predefined set of choices, such as routing a request or picking an agent, so the response can feel almost instant while keeping safety checks.
- ▸ Private intelligence is previewed as stronger data controls: zero-data-retention safety processing and private inference so sensitive work can use frontier models without storing content on OpenAI servers.
- ▸ The panel's live read is that much of the keynote copies patterns already shipping in other agent products, and the useful question is which pieces change day-to-day work rather than the launch theater.
